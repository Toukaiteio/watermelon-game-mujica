# 合成大祥脚 watermelon-game-mujica

Suika 风格的同人小游戏：把圆滚滚的角色球合成到一起，最终合成大祥脚。

纯 HTML / CSS / Canvas，无构建步骤，无需联网，离线打开 `index.html` 即可游玩。

## 玩法

- 点击 / 触摸棋盘上方掉落当前球，左右移动瞄准（有虚线引导）。
- 两个相同等级的球碰到一起会合成更高一级并加分。
- 只能掉落 1–5 级；两个 11 级相遇会抵消，+66 分并弹出“合成大祥脚！”。
- 球在危险线之上静止 1.5 秒即结算。
- PC 端：数据组件（分数、最高分、下一个、暂停 / 重开 / 音效）在棋盘右侧侧边栏；空间不够时自动移到顶部栏（高 48px）。
- 所有平台逻辑棋盘均为 398×800，公平一致。

## 等级

1 樱桃 - 要乐奈，2 草莓 - 千早爱音，3 葡萄 - 长崎爽世，4 丑橘 - 椎名立希，
5 柿子 - 高松灯，6 苹果 - 八幡海铃，7 梨 - 若叶睦，8 桃子 - 祐天寺若麦，
9 菠萝 - 纯田真奈，10 哈密瓜 - 三角初华，11 西瓜 - 祥脚。

## 设置

开始页的“设置”里可调音乐 / 音效音量、查看和清除最高分。
游戏页右上角的音效按钮只是快速静音 / 恢复，不会改动滑块和已保存的音量。

## 素材与署名

- 角色球为原创 Q 版圆球立绘，非官方立绘直接复用。
- 合并音效：swiimii 的 “Pop Sound Effect”（Freesound，CC BY 4.0）。
- 背景音乐与结算音乐为游戏内自带音频文件。
